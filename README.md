# Neckdown Pullover for Men — beginner's guide, size Large

A step-by-step beginner's guide to knitting the *Knitting Pure & Simple* pattern #991,
"Neckdown Pullover for Men" (a seamless top-down raglan), with every stitch count
worked out for the **Large** size (50-inch finished chest) and the **magic loop**
method used throughout.

Open `index.html` in a browser. It also prints cleanly.

## What's inside

- Overview, finished measurements and a schematic
- Shopping list (yarn, two long circular needles, notions)
- Skills glossary, tagged by when you need each technique
- Gauge swatch instructions
- Nine steps with a stitch-count checkpoint after each
- Fit adjustments, troubleshooting, and a one-page reference card
